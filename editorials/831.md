## 831A - Unimodal Array

Let use two variables *pos*<sub>1</sub> и *pos*<sub>2</sub>. Initially *pos*<sub>1</sub> = 0 and *pos*<sub>2</sub> = *n* - 1.

After that we need to iterate through the given array from the left to the right and increase *pos*<sub>1</sub> until the next element is strictly more than previous. After that we need to iterate through the given array from the right to the left and decrease *pos*<sub>2</sub> until *a*[*pos*<sub>2</sub> - 1] > *a*[*pos*<sub>2</sub>].

Now it is left only to check that all elements between positions *pos*<sub>1</sub> and *pos*<sub>2</sub> are equal to each other. If it is true the answer is "YES", otherwise, the answer is "NO".

## 830B - Cards Sorting

First note that operation "put a card under the deck" is the same as "stark viewing from the beginning when you reach the end", and do not move cards anywhere.

Then, let's proceed all cards with equal numbers on them at once. It's obvious that Vasily puts them away one after another. Let's denote the position where he was when he put the last card less than *x* be position *p* in the deck. Two cases are possible.

- If all cards equal to *x* are after position *p*, then he looks all the cards until he takes the last card with *x*, and puts away all cards equal to *x*;
- Otherwise there is a card with *x* that is before *p*. In this case Valisy looks at all cards from *p* to the end, and after that — at all cards from the beginning of the deck to the last card with *x* that is before *p*.

It's easy to process both cases if we keep for each *x* positions of all cards with *x* from the top to the bottom of the deck. Aside of this we need any data structure that is capable of computing sum on a segment and changing a single value (we can store 1 for a position with a card in the deck, and 0 is the card is already put away). We can use segment tree or Fenwick tree for example.

## 830C - Bamboo Partition

First fact: The problem is asking to maximize $d$ such that: $\sum_{i=1}^{n} (d \left \lceil{\frac{a_i}{d}}\right \rceil - a_i) \leq k$.

$\sum_{i=1}^{n} (d \left \lceil{\frac{a_i}{d}}\right \rceil - a_i) \leq k \Rightarrow d \sum_{i=1}^{n} \left \lceil{\frac{a_i}{d}}\right \rceil \leq k + \sum_{i=1}^{n} a_i$. Let $C = k + \sum_{i=1}^{n} a_i$, then $d \sum_{i=1}^{n} \left \lceil{\frac{a_i}{d}}\right \rceil \leq C$.

Second fact: Number of possible values for $\left \lceil{\frac{a}{b}}\right \rceil$ is $\mathcal{O}(\sqrt a)$.

For $x$, let $A = \left \lfloor{\sqrt{x}}\right \rfloor$ these values are $1 \cdots A$ and $\left \lceil{\frac{x}{1}}\right \rceil \cdots \left \lceil{\frac{x}{A}}\right \rceil$.

So there is at most $\mathcal{O}(n \cdot \sqrt {max_{i=1}^{n} a_i})$ segments for $d$ such that $\sum_{i=1}^{n} \left \lceil{\frac{a_i}{d}}\right \rceil$ will not change.

Now generate all possible values and sort them, and for each segment check if there is a $d$ in that segment satisfying the condition and update the answer.
