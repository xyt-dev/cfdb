## 838A - Binary Blocks

Let's define function *onesInRect*(*sx*, *sy*, *ex*, *ey*) as number of ones in rectangle with top-left (*sx*, *sy*) and down-right (*ex* - 1, *ey* - 1) (0-based).

Let *ps*<sub>*i*, *j*</sub> the number of ones in rectangle with top-left (0, 0) and down-right (*i* - 1, *j* - 1) (0-based).
*ps*<sub>*i*, *j*</sub> = *ps*<sub>*i* - 1, *j*</sub> + *ps*<sub>*i*, *j* - 1</sub> - *ps*<sub>*i* - 1, *j* - 1</sub>*onesInRect*(*sx*, *sy*, *ex*, *ey*) = *ps*<sub>*ex*, *ey*</sub> - *ps*<sub>*sx*, *ey*</sub> - *ps*<sub>*ex*, *sy*</sub> + *ps*<sub>*sx*, *sy*</sub>

## 838B - Diverging Directions

For each second type of query, there are two options:

- *u* is an ancestor of *v*.
- *u* isn't an ancestor of *v*.

Let's define distance *v* from root be *disFromRoot*<sub>*v*</sub>. Answer of the first type of second query is obviously *disFromRoot*<sub>*v*</sub> - *disFromRoot*<sub>*u*</sub>.

Let's define minimum possible distance *v* from some node in this subtree of v + the distance from this node to root be *minSubTreeDis*<sub>*v*</sub>. Answer of the second type of the second query is obviously *minSubTreeDis*<sub>*u*</sub> + *disFromRoot*<sub>*v*</sub>.

Now, let's see how to find *disFromRoot*<sub>*v*</sub>. For each vertex like *v*, let the weight of edge from its parent to it be *w*, you should add *w* to all of the subtree of *v*. Use segment tree with range updates and single element queries, sort vertices in dfs order, add *w* to [*startingTime*<sub>*v*</sub>, *finishingTime*<sub>*v*</sub>). Now *disFromRoot*<sub>*v*</sub> = *get*(*startingTime*<sub>*v*</sub>). We can handle update queries (first type) easily, just change the weight and update the segment tree again.

Now, let's see how to find *minSubTreeDis*<sub>*v*</sub>. Like above use segment tree with lazy propagation and minimum query.
