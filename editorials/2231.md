**Problem A**:



## 2231A - Construct an Array

One possible solution is the sequence of odd numbers $1, 3, \dots, 2n - 1$: notice that the sums of adjacent elements are always even.

Another example is the sequence of numbers not divisible by 3: $1, 2, 4, 5, 7, 8, \dots$. Here, the sums of adjacent elements are divisible by 3, since the residues modulo 3 form the pattern $1, 2, 1, 2, \dots$. One can check that the maximum number in this sequence does not exceed $1.5 \cdot n$, which comfortably satisfies the constraint $a_i \leq 2 \cdot n$.


**Code**
```python
t = int(input())
for tt in range(t):
 n = int(input())
 ans = [2 * i + 1 for i in range(n)]
 print(*ans)
```

## 2231B - Another Sorting Problem

Note that if $a_i \gt a_{i + 1}$ holds, then it is necessary to add $k$ to the element $a_{i + 1}$, where $k \geq a_i - a_{i + 1}$. Therefore, it must hold that $k \geq \max(0, a_1 - a_2, a_2 - a_3, \ldots, a_{n - 1} - a_n)$.

Let us show that if there exists a suitable $k$ and a sequence $b_1, \ldots, b_m$ such that the sequence becomes sorted, then we can take $k = \max(0, a_1 - a_2, a_2 - a_3, \ldots, a_{n - 1} - a_n)$ that is, the minimum possible $k$ that can potentially fix the array. To do this, consider several cases:

- If for index $i$ we added $k$ to both elements $a_i$ and $a_{i + 1}$, then changing $k$ does not change their relative order.
- If for index $i$ we added $k$ to element $a_i$, but did not add it to element $a_{i + 1}$, then, obviously, when decreasing $k$, the condition will still be satisfied. (Because of this case, it is necessary to take the minimum possible number.)
- If for index $i$ we added $k$ to element $a_{i + 1}$, but did not add it to element $a_i$, then the situation $a_{i + 1} + k \lt a_i$ can occur only if $a_i \gt a_{i + 1}$, but we chose $k$ large enough so that in this case, after the operation, $a_i \geq a_{i + 1} + k$ holds.

So the problem reduces to checking whether it is possible to add a fixed number to some elements so that the sequence becomes sorted. This can be done with a straightforward greedy algorithm: we go from left to right, and if $a_{i - 1} \gt a_i$, then it is necessary to perform $a_i := a_i + k$. If after such a pass the array is sorted, then the answer is "Yes", otherwise "No".

 
**Code**
```cpp
#include <bits/stdc++.h>

#define all(a) a.begin(), a.end()
#define rall(a) a.rbegin(), a.rend()
#define len(a) (int)(a.size())

#ifdef LOCAL
#define __lg(n) log2(n)
#endif

using namespace std;

using ll = long long;
using ull = unsigned long long;
using ld = long double;

template<typename T>
using PQ = priority_queue<T, vector<T>, greater<>>;

void solve() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
    }
    int mx = 0;
    for (int i = 0; i < n &mdash; 1; ++i) {
        mx = max(mx, a[i] &mdash; a[i + 1]);
    }
    for (int i = 1; i < n; ++i) {
        if (a[i] < a[i &mdash; 1]) {
            a[i] += mx;
        }
    }
    if (is_sorted(all(a))) {
        cout << "YES\n";
    } else {
        cout << "NO\n";
    }
}

signed main() {
    ios_base::sync_with_stdio(0);
    cin.tie(0);

    int t = 1;
    cin >> t;
    while (t--) solve();
}
```

## 2231C - Chipmunk Theo and Equality

For each $i = 1, \dots, n$, consider the sequence $(b^{(i)}_j)$ obtained by repeatedly applying operations to the element $a_i$: $$ b^{(i)}_0 = a_i, \qquad b^{(i)}_{j + 1} = \begin{cases} b^{(i)}_j + 1, & \text{if } b^{(i)}_j \text{ is odd}, \\ b^{(i)}_j / 2, & \text{if } b^{(i)}_j \text{ is even}. \end{cases} $$

Notice that at some point the sequence $b^{(i)}_0, b^{(i)}_1, \ldots$ reaches $1$, and from then on it becomes: [ 1, 2, 1, 2, 1, 2, ... ] Moreover, this happens after $O(\log a_i)$ operations, since among any two consecutive operations there is at least one division by $2$. Therefore, it is enough to keep only the prefix of the sequence up to this moment.

Now let us compute:

- $c_1[x]$ — the number of indices $i$ such that $x$ appears in the sequence $b^{(i)}$,
- $c_2[x]$ — the sum of positions of $x$ in $b^{(i)}$ over all $i$.

The answer is the value $x$ such that $c_1[x] = n$ and $c_2[x]$ is minimized.

The complexity of this solution is $O(n \log C)$, where $C = 10^9$.

The implementation can be optimized further by adding a value $x \in b^{(i)}$ to $c_1$ and $c_2$ only if $x$ also appears in $b^{(1)}$. Such an implementation uses $O(n)$ memory and easily fits within the limits.


**Code**
```python
for _ in range(int(input())):
 n = int(input())
 a = list(map(int, input().split()))
 cnt1 = dict()
 cnt2 = dict()
 x = a[0]
 a = a[1:]
 s = set()
 c = 0
 while x not in s:
 if x not in cnt1:
 cnt1[x] = 0
 cnt2[x] = 0
 cnt1[x] += 1
 cnt2[x] += c
 s.add(x)
 if x & 1:
 x += 1
 else:
 x >>= 1
 c += 1
 for x in a:
 s = set()
 c = 0
 while x not in s:
 if x in cnt1:
 cnt1[x] += 1
 cnt2[x] += c
 s.add(x)
 if x & 1:
 x += 1
 else:
 x >>= 1
 c += 1
 ans = 10 ** 18
 for k, v in cnt1.items():
 if v == n:
 ans = min(ans, cnt2[k])
 print(ans)
```

## 2231D - Maximum Prefix Sums

Let's find the position $i$ where $p_i \ne p_{i+1}$; they make the array into several subarrays.

- If $a_{i+1}$ is fixed, then you know the value of $b_i$. Then let $i \gets i - 1$.
- Otherwise, you can fill in a $-inf$ at the beginning of this subarray so that the maximum will never change in this subarray. Note that the $inf$ you can fill is much larger than the given element.
- At last, check whether the array $a$ we get is valid.
 Time complexity: $\mathcal O(n)$.

 
**Code**
```cpp
#include<bits/stdc++.h>
#ifdef DEBUG_LOCAL
#include <mydebug/debug.h>
#endif
using ll = long long;
const int N = 5e5+5;
using namespace std;
int T,n; string s; ll a[N],c[N],b[N],d[N];
void los(){
    cin >> n >> s,s = " " + s; d[0] = 1;
    for(int i = 1;i <= n;i ++) cin >> a[i],d[i] = 0;
    for(int i = 1;i <= n;i ++) cin >> c[i];
    c[0] = -1e18,b[0] = 0;
    for(int i = 1;i <= n;i ++){
        if(c[i] != c[i &mdash; 1]){
            if(c[i] < c[i-1]) return cout << "No\n",void();
            b[i] = c[i],d[i] = 1;
            for(int j = i;j >= 0;j --){
                if(s[j] == '1'){
                    if(d[j &mdash; 1] && b[j &mdash; 1] + a[j] != b[j]) return cout << "No\n",void();
                    d[j &mdash; 1] = 1,b[j &mdash; 1] = b[j] &mdash; a[j];
                }else break;
            }
        }
    }for(int i = 1;i <= n;i ++){
        if(s[i] == '1') b[i] = b[i-1] + a[i],d[i] = 1;
        if(!d[i]) b[i] = -1e16;
        a[i] = b[i] &mdash; b[i-1];
        if(max(c[i-1],b[i]) != c[i]) return cout << "No\n",void();
    }
    cout << "Yes\n";
    for(int i = 1;i <= n;i ++){
        cout << a[i] << " \n"[i == n];
    }
}int main(){
    ios::sync_with_stdio(0),cin.tie(0);
    for(cin >> T;T --;) los();
}
```

**Problem E**:



## 2231E - Graph Cutting

Let us consider separately the case when the cut subtree is a path in the tree. The number of such subtrees is easy to compute: it is the number of pairs of vertices at distance $d - 1$ multiplied by $d - 2$ (since any vertex on the path can be chosen as the third vertex).

Otherwise, the cut subtree will always have the following form:


![](eimages/2231_1.png)


That is, a path from which another path branches off. Let $v$ be the vertex where these paths intersect. Then the number of edges in this subgraph equals $\operatorname{dist}(a, v) + \operatorname{dist}(b, v) + \operatorname{dist}(c, v)$.

Root the tree at vertex $1$ and, for each vertex $v$, count the number of paths whose intersection of two such paths is at this vertex $v$. To compute the answer, we need the following arrays:

- $d_v$ — the distance from vertex $1$ to vertex $v$.
- $up_{v, k}$ — the number of vertices that are in the supertree (if the tree is rooted at vertex $1$) of vertex $v$ at distance $k$.
- $down_{v, k}$ — the number of vertices that are in the subtree of vertex $v$ at distance $k$.

These arrays can be easily computed in $O(n^2)$. We will maintain two values: $ans_1, ans_2$, which count the number of triples in the subtree and in the supertree, respectively (this will be described in more detail below).

Then, for a fixed $v$, we iterate over two vertices $v_1, v_2$ from different subtrees, which are two vertices from the chosen triple. Then there are two different positions for the third vertex: either in the subtree of $v$, or in the supertree:

- If it is in the subtree, then we need to add to $ans_1$ the value $down_{v, d - 1 - (d_v - d_{v_1}) - (d_v - d_{v_2})}$ (that is, the number of vertices in the subtree of vertex $v$ such that the total distance is equal to $d - 1$), and then subtract those vertices that are in the subtree containing either of the vertices $v_1$, $v_2$ (because $v$ is the intersection of the paths and the third vertex cannot be in the subtree of one of the chosen vertices).
- If it is in the supertree, then we need to add to $ans_2$ the value $up_{v, d - 1 - (d_v - d_{v_1}) - (d_v - d_{v_2})}$.

Then the answer is the number of triples whose union is a path, plus $\frac{ans_1}{3}$ plus $ans_2$, since if it is in the subtree, then we count each triple $3$ times. The complexity of this solution is $O(n^2)$, since each pair of vertices is counted at their lowest common ancestor.

There are also many alternative solutions to this problem.


**Code**
```cpp
#include <bits/stdc++.h>

#define all(a) a.begin(), a.end()
#define rall(a) a.rbegin(), a.rend()
#define len(a) (int)(a.size())

using namespace std;

using ll = long long;
using ld = long double;

const int N = 2228;

vector<int> G[N];
int tin[N], tout[N];
int timer = 0;
int cntup[N][N];
int cntdown[N][N];
ll ans1 = 0, ans2 = 0, ans3 = 0;

void solve_path(int n, int v, int d) {
 vector<int> dist(n);
 auto dfs = [&](auto &self, int v, int p, int h = 0) -> void {
 dist[v] = h;
 for (int i : G[v]) {
 if (i != p) self(self, i, v, h + 1);
 }
 };

 dfs(dfs, v, -1, 0);

 for (int i = v + 1; i < n; ++i) {
 if (dist[i] == d) {
 ans1 += d - 1;
 }
 }
}

void dfs_tin(int v, int p) {
 tin[v] = timer++;

 for (int i : G[v]) {
 if (i != p) dfs_tin(i, v);
 }
 tout[v] = timer;
}

void solve() {
 int n, d;
 cin >> n >> d;
 --d;
 for (int i = 0; i < n; ++i) G[i].clear();
 ans1 = 0, ans2 = 0, ans3 = 0, timer = 0;

 for (int i = 0; i < n - 1; ++i) {
 int a, b;
 cin >> a >> b;
 G[a - 1].push_back(b - 1);
 G[b - 1].push_back(a - 1);
 }

 for (int i = 0; i < n; ++i) solve_path(n, i, d);
 for (int i = 0; i < n; ++i) {
 fill(cntup[i], cntup[i] + N, 0);
 fill(cntdown[i], cntdown[i] + N, 0);
 }
 dfs_tin(0, -1);

 for (int i = 0; i < n; ++i) {
 auto dfs = [&](auto &self, int v, int p, int h) -> void {
 if (tin[i] <= tin[v] && tin[v] < tout[i]) ++cntdown[i][h];
 else ++cntup[i][h];

 for (int j : G[v]) {
 if (j != p) self(self, j, v, h + 1);
 }
 };

 dfs(dfs, i, -1, 0);
 }

 vector<int> h(n);
 auto dfs = [&](auto &self, int v, int p, int hh = 0) -> vector<int> {
 int m = len(G[v]);
 vector<vector<int>> who(m);
 vector<int> all;
 all.push_back(v);
 h[v] = hh;

 for (int i = 0; i < len(G[v]); ++i) {
 if (G[v][i] == p) continue;

 who[i] = self(self, G[v][i], v, hh + 1);
 for (int j : who[i]) all.push_back(j);

 for (int j = 0; j < i; ++j) {
 for (int v1 : who[i]) {
 for (int v2 : who[j]) {

 int D = h[v1] + h[v2] - 2 * hh;
 if (D >= d) continue;
 int need = d - D;
 ans2 += cntup[v][need];
 int cnt3 = cntdown[v][need];
 cnt3 -= cntdown[G[v][i]][need - 1];
 cnt3 -= cntdown[G[v][j]][need - 1];
 ans3 += cnt3;

 }
 }
 }
 }

 return all;
 };

 dfs(dfs, 0, -1, 0);
 cout << ans1 + ans2 + ans3 / 3 << '\n';
}

int main() {
 ios_base::sync_with_stdio(0);
 cin.tie(0);

 int t = 1;
 cin >> t;
 while (t--) solve();
}
```

## 2231F - Quadratic Jumps

Notice that the answer to a query does not exceed $4$ by Lagrange's four-square theorem. So it remains to learn how to check whether the answer is $1$, $2$, or $3$.

Let us learn how to answer whether the distance is equal to $2$ in $O(1)$; for this, we need to compute two arrays:

- $f(x)$ — whether $x$ can be represented as a sum of two squares $a^2 + b^2 = x$.
- $g(x)$ — the minimum $a$ such that there exists $b$ with $a^2 - b^2 = x$.

Each of these arrays can be computed in $O(n)$ by iterating over $a, b$ (since the number of distinct squares is at most $\sqrt{n}$).

Now let us solve the problem. To check that the answer is $1$, it is enough to verify that $b - a$ is a perfect square.

To check that the answer is $2$, it is enough to verify that either $f(b - a) = 1$, or that $g(b - a) \geq \max(a - 1, n - a)$. In the first case, we check that there exists a vertex $v$ such that $a \leq v \leq b$, and both $v - a$ and $b - v$ are perfect squares. In the second case, we check whether there exists a vertex $v$ such that $v \leq a \leq b$ or $a \leq b \leq v$ satisfying the condition.

To check that the answer is $3$, we can iterate over all possible first jumps (there are at most $\sqrt{n}$ of them), and for each of them check whether it is possible to reach the destination from that vertex in distance $2$.

The resulting complexity is $O(n + q \cdot \sqrt{n})$.

 
**Code**
```cpp
#include <bits/stdc++.h>
 
#define all(x) (x).begin(), (x).end()
#define allr(x) (x).rbegin(), (x).rend()
#define gsize(x) (int)((x).size())
 
const char nl = '\n';
typedef long long ll;
typedef long double ld;
 
using namespace std;
 
const int K = 450;
 
void solve() {
    int n, q;
    cin >> n >> q;
 
    vector<int> f(n, -1); // f[i] = -1 if impossible, 1 if i = a^2, 2 if i = a^2 + b^2
    for (int a = 1; a * a < n; a++) {
        for (int b = a; a * a + b * b < n; b++) {
            f[a * a + b * b] = 2;
        }
        
        f[a * a] = 1;
    }
    
    vector<int> g(n, -1); // g[i] = -1 if impossible, else min `b` over i = a^2 - b^2
    for (int b = 1; b * b < n; b++) {
        for (int a = b; a * a - b * b < n; a++) {
            int v = a * a - b * b;
            if (g[v] < 0) g[v] = b * b;
        }
    }
    
    while (q--) {
        int a, b;
        cin >> a >> b;
        
        int ans = 4;
        for (int d = -K; d <= K; d++) {
            int x = a + abs(d) * d;
            if (x <= 0 || x > n) continue;
            
            int ta = x, tb = b;
            if (ta > tb) swap(ta, tb);
            
            int tans = 4;
            {
                int v = tb - ta;
                if (g[v] > 0 && g[v] <= max(n - tb, ta - 1)) {
                    tans = 2;
                }
                
                if (f[v] > 0) {
                    tans = f[v];
                }
                
                if (d != 0) tans++;
            }
            
            ans = min(ans, tans);
        }
        
        cout << ans << nl;
    }
}
 
int main() {
	ios::sync_with_stdio(0); cin.tie(0);
    
    int t;
    cin >> t;
    while (t--) solve();
}
```
