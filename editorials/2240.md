### [Div2A. Another Popcount Problem](<https://codeforces.com/contest/2240/problem/A>)

Author: [wangmarui](<https://codeforces.com/profile/wangmarui>) Preparation: [wangmarui](<https://codeforces.com/profile/wangmarui>)

**Hint 1**

Consider each binary bit independently.


**Hint 2**

**Solution**

## 2240A - Another Popcount Problem

Since we can consider the problem from the lowest binary bit to the highest, the problem is equivalent to having $k$ copies of $2^0$, $k$ copies of $2^1$, $k$ copies of $2^2$, $\dots$, and so on. We want to find the maximum number of these values that can sum up to a value not exceeding $n$ (or matching the constraints).

By greedily selecting the smallest available powers of 2 first, we can achieve the optimal solution. The time complexity per testcase will be $\mathcal{O}(\log n)$, which easily passes within the time limit.

### [Div2B. AI Finds Nothing Here](<https://codeforces.com/contest/2240/problem/B>)

Author: [Gold14526](<https://codeforces.com/profile/Gold14526>) Preparation: [Gold14526](<https://codeforces.com/profile/Gold14526>)

**Hint 1**

Try some special cases, such as $r=c=2$, $n=r$, or $m=c$, etc.


**Solution**

In terms of systems of equations, the given problem fixes for us the parities of at most (and exactly) $(n-r+1)\cdot(m-c+1)$ cells (by giving us a system of equations to solve with that many equations). What this means is that, if we are to fill an upper border of thickness $r-1$ and a left border of thickness of $c-1$, then every cell from that point onward is determined uniquely by some equation (Tip: imagine how this pans out for a $2\times2$ matrix; after filling the first row and left column arbitrarily, cell (2,2) is uniquely determined, then (2,3), and so on).

Therefore, the answer is $2^{nm - (n-r+1)(m-c+1)}$.

### [Div1A. Nim Game Is XOR Game](<https://codeforces.com/contest/2239/problem/A>)

Author: [Gold14526](<https://codeforces.com/profile/Gold14526>) Preparation: [Gold14526](<https://codeforces.com/profile/Gold14526>)
 
**Hint 1**

Try working through some cases by hand. You may notice that whenever there is more than one non-zero number, the first player wins. Then think about why this is true.

 
**Solution**

## 2239A - Nim Game Is XOR Game

It can be proven that the first player is guaranteed to win as long as there are at least two non-zero numbers. Namely, the first player can always reduce the array to have at most one non-zero number remaining in a single operation. Let $X$ be the XOR sum of all elements. If $X = 0$, there is only one winning choice, which is to change all elements in $a$ to $0$. Otherwise, the answer is the number of indices $i$ such that $(a_i \oplus X) \le a_i$.

### [Div1B. Decidophobia](<https://codeforces.com/contest/2239/problem/B>)

Author: [Gold14526](<https://codeforces.com/profile/Gold14526>) Preparation: [Gold14526](<https://codeforces.com/profile/Gold14526>)

**Hint 1**

How does everyone’s contribution change when you give a gift to someone?


**Solution**

## 2239B - Decidophobia

Note that giving a gift to the $i$-th person increases their happiness by $2d \cdot a_i$ and decreases the happiness of the $d$ people on their left and the $d$ people on their right by $a_i$ each, regardless of whether those people had gifts or not. For this reason, we can observe that the decision for each person happens independently. Therefore, it is only necessary to calculate $2d \cdot a_i$ minus the sum of the weights of the $d$ people on both sides for each position, and then sum the positive values. The time complexity is $O(n)$.

### [Div1C. Revival](<https://codeforces.com/contest/2239/problem/C>)

Author: [Gold14526](<https://codeforces.com/profile/Gold14526>) Preparation: [Gold14526](<https://codeforces.com/profile/Gold14526>)
 
**Hint 1**

Consider determining all the numbers from back to front.

 
**Hint 2**

When you determine a number, subtract $1$ from all previous values that are greater than this number. This way, all $p$ values decrease by one, while all $s$ values remain unchanged. Now you only need to solve the problem of determining the last number.

 
**Solution**

## 2239C - Revival

We determine the values at the inversion-constrained positions by iterating backwards. Let the given inversion counts be $s_{x_1}, s_{x_2}, \dots, s_{x_m}$. For each $i$, the difference $s_{x_i} - s_{x_{i-1}}$ accounts for the inversions within $(x_{i-1}, x_i]$ and those between $[1, x_{i-1}]$ and $(x_{i-1}, x_i]$. By subtracting the contributions of known $p_j$ in $(x_{i-1}, x_i]$, we isolate the constraints on $p_{x_i}$. Specifically, the remaining value corresponds to the number of elements before $p_{x_i}$ that are greater than it, adjusted for the interactions within the local block. This allows us to determine $p_{x_i}$ uniquely in $O(n \log n)$ time using a BIT.

### [Div1D. Hunting the Beast](<https://codeforces.com/contest/2239/problem/D>)

Author: [Milkcat2009](<https://codeforces.com/profile/Milkcat2009>) Preparation: [Milkcat2009](<https://codeforces.com/profile/Milkcat2009>)

**Hint 1**

By symmetry, all vertices are equivalent. Therefore, we only need to calculate the number of graphs in which a specific set is successful, and then multiply by $\binom{n}{m}$.


**Hint 2**

**Hint 3**

The answer is $1-n$, which you can try to prove.


**Hint 4**

Use the Binomial Theorem to simplify the sum.


**Solution**

## 2239D - Hunting the Beast

Consider calculating the number of functional graphs for which a given set $S$ of size $m$ is the exact set of covered vertices (the image of the function). By symmetry, this is independent of the elements in $S$. The answer is the same for all sets $S$ of size $m$, so we can just compute the answer for $S=\{1,2,\cdots,m\}$ and multiply it by $\binom{n}{m}$.

Let's call the first $m$ vertices "key vertices", and the remaining ones "non-key vertices". Then, each pseudo-tree (connected component) in a valid functional graph must satisfy:

- If it is a pure cycle, it must contain at least one key vertex;
- Otherwise, if it is not a pure cycle, all its leaves must be key vertices.

This inspires us to use the Inclusion-Exclusion Principle: we designate some pure cycles that do not contain any key vertices, and designate some non-key vertices to be leaves. If we designate $k$ pure cycles and $j$ leaves, the inclusion-exclusion coefficient will be $(-1)^{k+j}$.

In the calculation of the number of ways, we only care about the total number of vertices in the designated pure cycles that do not contain key vertices. Therefore, we enumerate $i$ and $j$, designating $i$ non-key vertices to form pure cycles and $j$ non-key vertices to be leaves. We need to find $g_n$, which represents the sum of contributions over all ways to form several pure cycles without self-loops using $n$ vertices, where the contribution of having $k$ cycles is $(-1)^k$.

Let's consider how to compute $g_n$. First, let's look at the case where self-loops are allowed, denoting it as $f_n$. When $n \ge 2$, swapping the outgoing edges of vertices $1$ and $2$ yields a configuration with the opposite contribution. Thus, the contributions cancel each other out in pairs, giving $f_n=0$. For $n \lt 2$, we have $f_0=1$ and $f_1=-1$. Next, we use inclusion-exclusion to remove self-loops (by designating $i$ vertices as self-loops), which gives $g_n = \sum_{i=0}^n \binom{n}{i}(-1)^{2i}f_{n-i} = 1-n$ (where $(-1)^{2i}$ comes from the fact that the inclusion-exclusion principle contributes $(-1)^i$, and the self-loops themselves, being cycles, also contribute $(-1)^i$; multiplying them gives $1$).

The number of ways to choose these $i$ and $j$ vertices is $\binom{n-m}{i}\binom{n-m-i}{j}$. At this point, the coefficient for the pure cycle part is $g_i=1-i$, and the inclusion-exclusion coefficient for the leaf part is $(-1)^j$, so the total coefficient is $(-1)^j(1-i)$. The number of ways for the remaining part to arbitrarily form a functional graph is $(n-i-j)^j(n-i-j-1)^{n-i-j}$. Therefore, the answer is: $$ \begin{aligned} &\sum_{i=0}^{n-m}\sum_{j=0}^{n-m-i}(-1)^j(1-i)\binom{n-m}{i}\binom{n-m-i}{j}(n-i-j)^j(n-i-j-1)^{n-i-j}\\ =&\sum_{k=0}^{n-m}\binom{n-m}{k}(n-k-1)^{n-k}\sum_{i=0}^{k}(1-i)\binom{k}{i}(k-n)^{k-i} \end{aligned} $$

Simplifying the latter part: $$ \begin{aligned} &\sum_{i=0}^{k}(1-i)\binom{k}{i}(k-n)^{k-i}\\ =&\sum_{i=0}^{k}\binom{k}{i}(k-n)^{k-i}-\sum_{i=0}^{k}\binom{k}{i}i(k-n)^{k-i}\\ =&(k-n+1)^k-k\sum_{i=1}^{k}\binom{k-1}{i-1}(k-n)^{k-i}\\ =&(k-n+1)^k-k(k-n+1)^{k-1}\\ =&(1-n)(k-n+1)^{k-1} \end{aligned} $$

Thus, the final formula for the answer is: $$ \begin{aligned} &\sum_{k=0}^{n-m}\binom{n-m}{k}(n-k-1)^{n-k}(1-n)(k-n+1)^{k-1}\\ =&(n-1)\sum_{k=0}^{n-m}(-1)^k\binom{n-m}{k}(n-k-1)^{n-1} \end{aligned} $$

This formula can be computed in $\mathcal{O}(n)$ time (using a linear sieve to compute powers) or in $\mathcal{O}(n\log n)$ time.

## 2239E - The end of this world,

First, let's rephrase the problem: each edge exists during the time interval $[low_i, w_i]$. Given that your travel speed is infinite, the objective is to maximize the sum of your departure time and the weight of the destination. This is equivalent to maintaining a dynamic graph where you need to support edge additions, deletions, and calculating the maximum value within connected components.

Considering this as a dynamic connectivity problem, we can use a segment tree divide-and-conquer approach. During the recursion, for each node in the segment tree representing a time interval, we add all edges that fully cover this interval into the DSU. We then re-label the endpoints of these edges to their representative nodes in the DSU and recurse further. When passing down the tree, we push the maximum $val$ to the representative nodes. When a connected component is updated with a "take maximum" operation, we apply a lazy tag to the corresponding position. Finally, as we return from the recursion, we push down these tags to the connected components.

The time complexity is $O(m \log m)$.

**Solution**

## 2239F - Colorful Works

Consider the case where $l_i=0$, and let $a_i=r_i$.

It is natural to use DP to solve this. Let $f_{c,a}$ denote the number of ways to construct a tree based on the sequence $a$, where the root is connected to an upward edge of color $c$ (this includes the tree with 0 nodes).

Let $\text{dec}(a,i)$ denote the sequence $a$ after the operation $a_i\gets a_i-1$. The transition is straightforward: $$f_{c,a}=1+\prod_{i\neq c\land a_i \gt 0}f_{i,\text{dec}(a,i)}$$

Note that under modulo 2, if we treat $f_{c,a}=1$ as a winning state and $f_{c,a}=0$ as a losing state, this becomes a game process.

The problem is transformed into:

- Given a sequence $a$;
- Two players take turns. In each turn, a player chooses an $i$ such that $a_i \gt 0$ and decrements $a_i$ by 1, but the chosen $i$ cannot be the same as the color chosen by the previous player in the immediately preceding turn (there is no restriction for the first move);
- The player who cannot make a move loses. We want to determine if the first player has a winning strategy.

Let $S=\sum a_i$. It is easy to observe that if there exists an $i$ such that $2a_i \gt S$, the first player can win by repeatedly choosing color $i$. Since the first player wins whenever $2a_i \gt S$, neither player wants to move into a state where this condition becomes true for the opponent. If $2a_i \le S$ initially, it can be shown that there always exists a move such that $2a_i \le S$ remains true for the next state. Therefore, both players will always take turns reducing $S$ by 1. Consequently, if $S$ is odd, the first player wins; otherwise, the second player wins.

Note that since the tree with 0 nodes is not counted in the final answer, if the first player wins the game, the answer is $0$; otherwise, the answer is $1$. In summary:

- If $2\max a_i \gt \sum a_i$, the answer is $0$;
- Otherwise, the answer is $(1+\sum a_i)\bmod 2$.

For the general problem, according to the Principle of Inclusion-Exclusion, the answer is equal to the sum of the results over all possible ways to choose an upper bound for each color from $\{l_i-1, r_i\}$ (if $l_i=0$, only $r_i$ can be chosen).

Ignore the first condition ($2\max a_i \gt \sum a_i$) for a moment and calculate the answer based on the second condition ($S \bmod 2$); this part is easy. The problem then reduces to calculating the number of scenarios where $2\max a_i \gt \sum a_i$ and $\sum a_i$ is even. Let $b_i=l_i-1$ and $c_i=r_i$ (we ignore the $l_i=0$ corner case here for simplicity, but it is also easy to handle).

Enumerate the position $k$ of the maximum value $a_i$, and then enumerate the value of $a_k$. Next, we need to choose values for the remaining positions such that their sum has the same parity as $a_k$ and is within the range $[0, a_k)$.

Using generating functions for the derivation, the answer is equal to: $$ \begin{aligned} & \sum_{i=1}^n\left([x^{b_i}]\frac{x^2\prod_{j\neq i}(x^{b_j}+x^{c_j})}{1-x^2}+[x^{c_i}]\frac{x^2\prod_{j\neq i}(x^{b_j}+x^{c_j})}{1-x^2}\right) \\ = & [x^0]\left(x^2(1-x^2)^{-1}\prod_{i=1}^n(x^{b_i}+x^{c_i})\cdot \sum_{i=1}^n(x^{-b_i}+x^{-c_i})(x^{b_i}+x^{c_i})^{-1}\right) \\ = & [x^0]\left(x^2(1-x^2)^{-1}\prod_{i=1}^n(x^{b_i}+x^{c_i})\cdot \sum_{i=1}^nx^{-(b_i+c_i)}\right) \\ = & [x^0]\left(x^2(1-x^2)^{-1}\prod_{i=1}^n(1+x^{\lvert b_i-c_i\rvert})\cdot \sum_{i=1}^nx^{-(b_i+c_i)+\sum\min(b_j,c_j)}\right) \end{aligned} $$

Therefore, we only need to find the first $m$ terms of the product $\prod_{i=1}^n(1+x^{\lvert b_i-c_i\rvert})$.

Under modulo 2, we have the property $(1+x^k)^2=1+x^{2k}$. Thus, we can repeatedly merge identical factors of $(1+x^k)$ until all factors are distinct. Only factors where $k\le m$ are relevant, so we only need to compute the product of at most $m$ distinct binomials.

We can use bitset to optimize the polynomial multiplication by these binomials. The total complexity is $\mathcal O(m^2/w)$.

Remember to handle the $l_i=0$ corner case appropriately.
