## 741A - Arpa's loud Owf and Mehrdad's evil plan

Make a directed graph and put edge from *i* and *crush*<sub>*i*</sub>. If the graph has vertex such that its in-degree is 0 then obviously answer doesn't exist. Otherwise, the graph consists of some cycles. For each cycle suppose that its length is *len*. If it has odd length, add *len* to *S*, otherwise, add *len* / 2.

The answer is the LCM of numbers in *S*.

## 741B - Arpa's weak amphitheater and Mehrdad's valuable Hoses

It’s a simple knapsack problem. Let’s solve this version of knapsack problem first: we have *n* sets of items, each item has value and weight, find the maximum value we can earn if we can choose at most one item from each set and the sum of the chosen items must be less than or equal to *W*. Let *dp*<sub>*w*</sub> be the max value we can earn if the sum of weights of chosen items is less than or equal to *w*. Now iterate on sets one by one and update *dp* as follows: for each item *X*, and for each weight *w*, *newDp*<sub>*w*</sub> = *max*(*newDp*<sub>*w*</sub>, *oldDp*<sub>*w* - *X*.*weight*</sub> + *X*.*value*).

Run dfs and find groups at first. The problem is same with above problem, each group is some set in above problem, just add the whole group as an item to the set that related to this group.

Time complexity:

![](eimages/742_16.png)

## 741D - Arpa’s letter-marked tree and Mehrdad’s Dokhtar-kosh paths

Please read [my dsu on tree (sack) tutorial](<https://codeforces.com/blog/entry/44351>) before you read.

Let’s calculate for each vertex such *v*, length of longest Dokhtar-kosh path that starts in some vertex of subtree of *v*, passes from *v*, and ends in some other vertex of subtree of *v* using sack (explained below); then we can sum up this values and get answer for each vertex.

First keep a mask for each vertex, *i*-th bit of *mask*<sub>*v*</sub> is *true* if the number of edges on the path from the root to *v* such that the letter *i* is written on them is odd. Now if the number of bits in

![](eimages/742_18.png)

 is 0 or 1, the path between *v* and *u* is Dokhtar-kosh.

Let’s use sack, assume *bag*<sub>*Mask*</sub> is the maximum height for a vertex that is present in our sack and its *mask* is equal to *Mask*.

Let’s define two functions used in sack:

*AddToSack*(*vertex* *x*) : If *bag*<sub>*mask*<sub>*x*</sub></sub> is less than *h*<sub>*x*</sub>, set *bag*<sub>*mask*<sub>*x*</sub></sub> = *h*<sub>*x*</sub>.

*UpdateCurrentAnswer* (*vertex* *x*, *vertex* *root*) : For each *Mask* such that

![](eimages/742_19.png)

 has at most one bit, update the *CurrentAnswer*, with *h*<sub>*x*</sub> + *bag*<sub>*Mask*</sub> - 2·*h*<sub>*root*</sub> (updating means if *CurrentAnswer* is less than *h*<sub>*x*</sub> + *bag*<sub>*Mask*</sub> - 2·*h*<sub>*root*</sub>, set *CurrentAnswer* to it).

Suppose dfs function arrives to vertex *v*. Call dfs for each child of *v* except the biggest one (which has more vertices in its subtree than others) and clear the sack each time. Call dfs for big child of *v* and don’t clear the sack. Then for each other child *u* and for each vertex

![](eimages/742_20.png)

, call *UpdateCurrentAnswer*(*x*, *v*). Then for each vertex

![](eimages/742_21.png)

, call *AddToSack*(*x*). After the addition of the children is done, call *UpdateCurrentAnswer*(*v*, *v*) and *AddToSack*(*v*). Now the answer for this vertex is *CurrentAnswer*.

To clear the sack, for each vertex

![](eimages/742_22.png)

 set *bag*<sub>*mask*<sub>*x*</sub></sub> =  - *inf* (i.e.  - 10<sup>9</sup>) and set *CurrentAnswer* to 0.

Note that there exists another solution using centroid decomposition, but it’s harder.
