## 2185A - Perfect Root

**Hint 1**

Fix an integer $x$, how could you find out the value of $y$?


**Hint 2**

Square both sides of the equation, for what values of $x$ is $x^2$ an integer?




Notice that for every positive integer $x$, $\sqrt{x^2} = x$. Therefore, we can conclude that every positive integer is a perfect root.

The problem then boils down to "Output $n$ distinct positive integers", which can simply be solved by outputting the sequence $1, 2, 3, \ldots, n$.

Time Complexity: $O(N)$


**Code**
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
 int t;
 cin >> t;

 while (t--) {
 int n;
 cin >> n;

 for (int i = 0; i < n; i++) cout << i+1 << " ";
 cout << "\n";
 }
}
```

## 2185B - Prefix Max
 
**Hint 1**

If we were to change the problem such that you could perform as many swaps as you wanted, the answer would remain the same.

 
**Hint 2**

Once our running sum encounters the maximum element of the array, the max of that prefix will always be the maximum element of the array.

 
**

If $max(a)$ is not the first element in the array, we can swap the first element with the maximum element. Otherwise, we can choose not to perform a swap. Since the maximum element is the first element of the array, the maximum value will be equal to $max(a) * n$.

Time Complexity: $O(N)$.

 
**Code**
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int t;
    cin >> t;

    while (t--) {
        int n;
        cin >> n;

        vector<int> vec(n); 
        for (auto &x: vec) cin >> x;

        cout << *max_element(vec.begin(), vec.end()) * n << "\n";
    }
}
```

## 2185C - Shifted MEX

**Solution 1: Hint 1**

Duplicate values don't matter, nor does the order of the elements.


**Solution 1: Hint 2**

Let's consider the inverse problem, where we have a array that is equal to [$0, 1, 2, \ldots, k-1$] and we can add $x$ to each value in the array. No matter which value of $x$ we choose, the values in $a$ are consecutive.


**Solution 2: Hint 1**

In order for the MEX to be greater than 0, 0 has to be contained in the array.


**Solution 2: Hint 2**

Since there are at most $3000$ elements in $a$, there are $3000$ possible values of $x$ that have a MEX greater than 0.




Solution 1:

Firstly, let's only consider distinct elements of the array, since a duplicate value won't affect the value of $\operatorname{MEX}$.

An array with a $\operatorname{MEX}$ of $n$ is an array such that all values from $0$ to $n-1$ are in the array (unless the $\operatorname{MEX}$ is 0, in which case the number 0 isn't in the array), but $n$ isn't. Let's consider an array $b$, which contains all of the elements that impact the $\operatorname{MEX}$ of the array.

Notice how all the elements in array $b$ are sequential, meaning that if the array were sorted, the difference between adjacent elements would be 1. Since we can add or subtract a value from all elements in the subarray through the operation, our answer is the longest sequential subsequence of the array $a$. The simplest way to compute this would be to remove duplicate elements from the array, sort it, and find the longest sequential subarray.

Time Complexity: $O(NlogN)$

Solution 2:

In order for the MEX to be greater than or equal to $0$, $0$ has to be present in the array. In order for there to be a $0$, $x$ has to be present in $a$, (since there has to be a value where $a_i - x = 0$). Therefore, we can try every value of $x$ that's in $a$, which is at most $n$ different values.

Time Complexity: $O(N^2)$


**Solution 1: Code**
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
 int t;
 cin >> t;

 while (t--) {
 int n;
 cin >> n;

 vector<int> vec(n);
 for (auto &x: vec) cin >> x;

 sort(vec.begin(), vec.end());
 // Remove duplicates
 vec.erase(unique(vec.begin(), vec.end()), vec.end());
 n = vec.size();
 int best = 0;
 int current = 0;
 for (int i = 0; i < n; i++) {
 if (i == 0 || vec[i] != vec[i-1]+1) {
 current = 0;
 }
 current++;
 best = max(best, current);
 }
 cout << best << "\n";
 }
}
```

 
**Solution 2: Code**
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int t;
    cin >> t;

    while (t--) {
        int n;
        cin >> n;

        vector<int> vec(n); 
        for (auto &x: vec) cin >> x;

        int best = 0;
        for (auto &x: vec) {
            int next = 0;
            for (int i = 0; i < vec.size(); i++) {
                if (vec[i]-x == next) next++;
            }
            best = max(best, next);
        }
        cout << best << "\n";
    }
```

## 2185D - OutOfMemoryError

**Hint 1**

Clearly, resetting all of the values is too slow, but we don't have to update all the elements at the same time.


**Hint 2**

If an element hasn't been modified after the last crash, it's value in the final array is the same as its value in the original array.




Solution 1

Whenever a reset occurs, we don't have to update all of the elements all at once. Keep track of the last reset, along with the last time an element has been modified. When we modify an element, if the last time it was modified earlier (or equal, depending on your implementation) than the time we last reset the array, reset the element to its original value. After all operations, we can go through each element in the array, and check if the last time the element was modified is earlier (or again, equal depending on your implementation) than the last reset, and if it is, we can reset the value to its original value.

The below two solutions are not recommended for Div4 participants, and are solely here because why not. If you were unable to solve this problem, you should not be learning about lazy segtree, rather practicing more problems.

Solution 2

Simulate the process as normal, but instead of resetting the entire array, keep track of the last time each element was updated, along with the most recent reset. If we're updating an element that was most recently updated before the last reset, reset its value. Finally, when outputting the original array, for each element, check to see if it was updated after the last reset. If it was, output its current value. If it wasn't, output its original value.

Solution 3

Consider the alternative problem where every element was set to 0 instead of its original value. We can use a lazy segment tree to simulate these operations. Note that the only time an element is equal to 0 in this new scenario is if its initial value was 0 or if it was reset to 0. Therefore, we can simulate as normal, but whenever we see an element with a value of 0, set it to its original value.


**Code**
```cpp
#include <bits/stdc++.h>
using namespace std;
#define ll long long
int main() {
 int t;
 cin >> t;

 while (t--) {
 int n, m, k;
 cin >> n >> m >> k;

 vector<int> vec(n); for (auto &x: vec) cin >> x;
 vector<int> original_vec(n); for (int i = 0; i < n; i++) original_vec[i] = vec[i];
 vector<int> last_element_update(n, -1);
 int last_reset = -1;
 int reset_count = 0;
 for (int i = 0; i < m; i++) {
 int a, b;
 cin >> a >> b;
 a--;

 if (last_element_update[a] < last_reset) vec[a] = original_vec[a];
 vec[a] += b;
 if (vec[a] > k) {
 last_reset = i;
 reset_count++;
 vec[a] = original_vec[a];
 }
 last_element_update[a] = i;
 }

 ll sum = 0;
 for (int i = 0; i < n; i++) {

 if (last_element_update[i] < last_reset) vec[i] = original_vec[i];
 cout << vec[i] << " ";
 }
 cout << "\n";

 }
}
```

## 2185E - The Robotic Rush
 
**Hint 1**

Each robot's movements is independent of another robot's movements.

 
**Hint 2**

We only need to care about the spikes directly to the right and left of the robot, if they exist.

 
**Hint 3**

To figure out when a robot dies, we don't need to care about the position of the robot, only the distance to its left and right spikes.

 
**Hint 4**

We only care about the left-most a robot has been and the right-most a robot has been.

 
**

We can store the distance to the spikes directly to the left and right of each robot, which can be calculated by either sorting $b$ and using binary search for each robot or by sorting both $a$ and $b$ and using a two-pointer approach. Once we have that, we can iterate through the instructions and store the deviation of the robot from its original position. After processing each instruction, we can check our current deviation from the center and check to see if there are any robots that will die if there is a spike at the current location, which we can do by using a map (or simply a vector, since the deviation range is from [-k, k]) where map[$x$] contains the robots that will die if the deviation is equal to $x$.

Make sure not to double count robots, so if a robot dies from its left spike and later dies from its right spike, it shouldn't be counted twice.

 
**Code**
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int t;
    cin >> t;

    while (t--) {
        int n, m, k;
        cin >> n >> m >> k;

        vector<int> robots(n); for (auto &x: robots) cin >> x;

        vector<int> lava(m); for (auto &x: lava) cin >> x;

        vector<bool> dead(n); 
        map<int, vector<int>> death_locations;

        string instructions;
        cin >> instructions;

        sort(lava.begin(), lava.end());

        for (int i = 0; i < n; i++) {
            if (lava[0] < robots[i]) {
                int left_dist = robots[i] - (*(lower_bound(lava.begin(), lava.end(), robots[i]) - 1));
                death_locations[-left_dist].push_back(i);
            }
            if (lava[m-1] > robots[i]) {
                int right_dist = *lower_bound(lava.begin(), lava.end(), robots[i]) - robots[i];
                death_locations[right_dist].push_back(i);
            }
            
        }

        int current_pos = 0;
        int alive = n;

        for (auto &x: instructions) {
            if (x == 'L') current_pos--;
            else current_pos++;

            for (int i: death_locations[current_pos]) {
                
                if (dead[i]) continue;
                dead[i] = true;
                alive--;
            }
            death_locations[current_pos].clear();
            cout << alive << " ";
        }

        cout << "\n";
    }
}
```

## 2185F - BattleCows

**Hint 1**

A single cow will only face $n$ matches.


**Hint 2**

XOR is cumulative, meaning the order of the cows in a stack doesn't change its skill level.


**Hint 3**

Similarly, the order of the cows in the stack doesn't change the final position of the cow who was given the potion in the final line.


**Hint 4**

You can calculate range XOR queries in O(1) using prefix sum.




Firstly, note that, since the XOR operation is cumulative, the skill level of the $i$ th cow after $k$ rounds will always be the same, and it will be the XOR of all the cows in that cow's line XOR the cow's skill level. This means that we only need to simulate the matches involving the cow who was given the potion, and we can calculate the skill level of the opponent by taking the XOR of all cows the opponent has fought XOR the opponent's skill level. The simplest way to calculate this is by using a prefix sum. Whenever the cow that was given the potion loses (or the leader of the line it's in loses), add $x$ to its position, where $x$ is equal to the number of cows in the opponent's line + 1.


**Code**
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
 int t;
 cin >> t;

 while (t--) {
 int n, q;
 cin >> n >> q;

 int num_cows = (1<<n);
 vector<int> cows(num_cows); for (auto &x: cows) cin >> x;

 vector<int> prefix(num_cows); prefix[0] = cows[0];
 for (int i = 1; i < num_cows; i++) {
 prefix[i] = cows[i] ^ prefix[i-1];
 }

 while (q--) {
 int cow_idx, skill_level;
 cin >> cow_idx >> skill_level;
 cow_idx--;

 int curr_position = 0;
 for (int i = 0; i < n; i++) {
 int size = (1<<i);
 int leader_idx = cow_idx / size;

 int leader_value = prefix[(size)*(leader_idx+1)-1] ^ (leader_idx == 0 ? 0 : prefix[(size)*(leader_idx)-1]);
 leader_value ^= cows[cow_idx];
 leader_value ^= skill_level;

 int enemy_value;
 if (leader_idx % 2 == 0) {
 enemy_value = prefix[(size)*(leader_idx+2)-1] ^ prefix[(size)*(leader_idx+1)-1];
 }
 else {
 enemy_value = prefix[(size)*(leader_idx)-1] ^ ((leader_idx-1) == 0 ? 0 : prefix[(size)*(leader_idx-1)-1]);
 }
 if (leader_value < enemy_value || (leader_value == enemy_value && leader_idx % 2 == 1)) {
 curr_position += size;
 }
 }

 cout << curr_position << "\n";
 }
 }
}
```

## 2185G - Mixing MEXes
 
**Hint 1**

The only time adding an element changes the MEX of an array is if the added element is equal to the MEX of the array.

 
**Hint 2**

For a given element, the element is removed $n - 1$ times, and the element is added to another array $n - 1$ times.

 
**Hint 3**

We can treat removing an element from the array and adding it to another array as two separate interactions.

 
**

Let's rephrase the operation as follows

- Remove the $i$ th element from array $a_j$, and add it to array $a_k$.
 We can calculate the effect of both of these independently.
For the removal operation, acknowledge that if a number is greater than the $\operatorname{mex}$ of the array, it doesn't change the $\operatorname{mex}$. Additionally, if a number occurs more than once in the array, removing any instance of the number doesn't change the $\operatorname{mex}$ of the array. Therefore, we can conclude the following criteria:

- If a number $x$ is greater than the $\operatorname{mex}$ or occurs more than once in the array, then there is no effect of removing the element.
- Otherwise, the $\operatorname{mex}$ of the array is set to $x$.

For the addition operation, acknowledge that if we add an element to an array, it only changes the $\operatorname{mex}$ of the array if the element is equal to the $\operatorname{mex}$, in which case the $\operatorname{mex}$ of the array will be changed to the $\operatorname{secondMex}$ of the array, or the second smallest positive integer that is not present in the array.

Implementations may vary; the below solution is one example of a valid way to do it.

Time Complexity: $O(N)$ or $O(NlogN)$ depending on implementation.

 
**Code**
```cpp
#include <bits/stdc++.h>
using namespace std;
 
#define ll long long
 
int main() {
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
 
        vector<int> lengths(n);
        vector<vector<int>> arrays(n);
        map<int, int> count;
        for (int i = 0; i < n; i++) {
            int length;
            cin >> length;
            lengths[i] = length;
            arrays[i] = vector<int>(lengths[i]);
            for (auto &x: arrays[i]) {
                cin >> x;
                count[x]++;
            }
            sort(arrays[i].begin(), arrays[i].end());
        }
 
        int mex_sum = 0;
        vector<int> mexes(n);
        vector<int> second_mexes(n);
 
        // Calculate mex and second mex for each array
        for (int i = 0; i < n; i++) {
            int current_mex = 0;
            for (int j = 0; j < lengths[i]; j++) {
                if (arrays[i][j] > current_mex) break;
                if (arrays[i][j] == current_mex) current_mex++;
            }
            int second_mex = current_mex+1;
            for (int j = 0; j < lengths[i]; j++) {
                if (arrays[i][j] > second_mex) break;
                if (arrays[i][j] == second_mex) second_mex++;
            }
            mexes[i] = current_mex;
            second_mexes[i] = second_mex;
            mex_sum += current_mex;
        }
 
        ll total = 0;
        // Calculate removals
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < lengths[i]; j++) {
                ll org = total;
                bool is_alone = (j == 0 || arrays[i][j-1] != arrays[i][j]) && (j == lengths[i]-1 || arrays[i][j+1] != arrays[i][j]);
                if (is_alone && arrays[i][j] < mexes[i]) total += ((ll)(mex_sum-mexes[i]+arrays[i][j]))*(n-1);
                else total += (ll)(mex_sum) * (n-1);
            }
        }
        // Calculate additions
        for (int i = 0; i < n; i++) {
            total += (ll)(count[mexes[i]])*(second_mexes[i]-mexes[i]);
        }
 
        cout << total << "\n";
    }
    
}
```

## 2185H - BattleCows 2

**Hint 1**

I had originally proposed this problem with a subtask to solve for Cow 0 only, try that.

**Hint 1.1**

Trivially, a cow must cheat when it loses a match, and a cow shouldn't cheat if it can win a match


**Hint 1.2**

Simulate the process for Cow 0 starting at position 0. If Cow 0 wins all of its matches in under $k$ cheats, Cow 0 can win all of its matches.


**Hint 1.3**

If we simulate the process for Cow 0 starting at position 0, no matter which position Cow 0 starts, after $k$ matches, if Cow 0 has already had a match, its skill value would be the same no matter in which position it initially started.


**Hint 1.4**

A cow can always win its first match using at most one hint, and so if there's another earlier position where Cow 0 had already used a cheat and won all of its matches, Cow 0 can also win in this new position.


**Hint 1.5**

Going back to the second hint, if Cow 0 used over $k$ cheats (let's call the number of cheats used $m$), Cow 0 can only win if its first match's match number is greater than or equal to the round number where Cow 0 at position 0 has used its $m - k$-th cheat.


**Hint 1.6**

Now we're down to the case we used exactly $k$ cheats. Let's denote the last position where Cow 0 can win its first match without cheating as $b$ (which is the first index where the sum of all the skill levels of the cows before is less than the skill level as cow 0). Using hint 3, this means that all the positions less than or equal to $b$ are also winning positions.


**Hint 1.7**

Finally, using hint 4, if Cow 0's first match is the same match or after the match where Cow 0 at position 0 could used its first cheat, cow 0 can win at that new position. Note that if $k = 0$, we can ignore this step.


**Hint 2**

We can simulate each cow as if it started as position 0.


**Hint 3**

A cow only needs cheat at most $\log(max(a_i))$ times, since its skill level is (at least) double after each cheat.


**Hint 4**

Prefix sums, binary search, and helper methods are your friend.




Firstly, read the hints to solve for a cow at position $0$.

For each cow, we can move it to position $0$ and simulate the round in $O(\log(n) * \log(\operatorname{max}(a_i))$ per cow. Since each cow can only cheat at most $\log(max(a_i))$ times, we can perform the following process:

- Create a prefix sum of the skill levels. Additionally, create a helper method to get the sum of a range of cows if cow $x$ has been removed from its spot and moved to position $0$.
- While we haven't completed every match, binary search for the first index where prefix[i] is greater than double the skill level of cow $x$. If $a_i \gt prefix[i - 1]$, add $i$ to an array of cheating positions.

Once we have finished simulating the process, we can use the same casework from the solution for hint 1 to find the number of good positions.

Total time complexity: $O(n\log(n)\log(\operatorname{max}(a_i)))$


**Code**
```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

int main() {
 int t;
 cin >> t;

 int test_num = 0;
 while (t--) {
 int n, k;
 cin >> n >> k;
 test_num++;
 vector<ll> skill_levels(n); for (auto &x: skill_levels) cin >> x;

 vector<ll> prefix(n); prefix[0] = skill_levels[0];
 for (int i = 1; i < n; i++) prefix[i] = skill_levels[i] + prefix[i-1];

 auto sum_without_index = [&](int l, int r, int i) {
 if (r < l || r < 0 || l < 0) return 0ll;
 ll val = prefix[r] - (l == 0 ? 0 : prefix[l-1]);
 if (r < i) return val;
 if (l > i) {
 r++;
 l++;
 return prefix[r] - (l == 0 ? 0 : prefix[l-1]);
 }
 else {
 r++;
 return prefix[r] - (l == 0 ? 0 : prefix[l-1]) - skill_levels[i];
 }

 };

 auto bs_for_prefix = [&](ll target, int ignoring) {
 int lo = 0;
 int hi = n - 1;
 while (lo <= hi) {
 int mid = lo + (hi - lo) / 2;
 if (mid == 0 || sum_without_index(0, mid-1, ignoring) < target) {
 lo = mid + 1;
 }
 else {
 hi = mid - 1;
 }
 }
 return hi;
 };

 vector<int> answer(n);
 for (int i = 0; i < n; i++) {
 int last_starting_position = bs_for_prefix(skill_levels[i], i);

 vector<int> bad_positions;
 int pos = -1;

 while (true) {
 ll value = sum_without_index(0, pos, i) + skill_levels[i];

 ll pos_of_bad = bs_for_prefix(value * 2 + 1 - skill_levels[i], i);

 if (pos_of_bad >= n - 1) break;

 value = sum_without_index(0, pos_of_bad-1, i) + skill_levels[i];

 bool bad_position = sum_without_index(pos_of_bad, pos_of_bad, i) > value;

 if (bad_position) {
 bad_positions.push_back(pos_of_bad + 1);
 }
 pos = pos_of_bad;
 }

 if (k == 0) {
 if (bad_positions.size() == 0) answer[i] += last_starting_position + 1;
 }
 else if (bad_positions.size() > k) {
 answer[i] += n - bad_positions[bad_positions.size() - k];
 }
 else if (bad_positions.size() < k) {
 answer[i] += n;
 }
 else {
 answer[i] += min(n, (last_starting_position + 1) + (n - bad_positions[0]));
 }
 }

 for (auto &x: answer) cout << x << " ";
 cout << "\n";

 }
}
```
