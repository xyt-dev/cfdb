## 2246A - farmpiggie and Subset Sum

**Hint 1**

Try to eliminate a large class of possible sums.


**Hint 2**

Think about parity. Is it possible to eliminate all odd numbers?


**Solution**

There are many solutions to this problem. One solution is to place all the even numbers on odd indices and all the odd numbers on even indices, so that $p_i \cdot i$ is always an even number. This way, the counter will always be even (hence it cannot be $1$). Note that since $n$ is even one could achieve this by simply printing the numbers $1,\ldots,n$ in reverse order (as $i$ and $n - i + 1$ must have opposite parity).

## 2246B - ezraft and Array

**Hint**

Try to construct the solution iteratively, by adding each new element.


**Solution**

A construction exists for all $n \neq 2$.

First, consider the case $n = 2$, and suppose a solution $a = [x, y]$ exists. Since $a$ and $b$ both divide $a+b$, $\text{lcm}(a, b)$ must also divide $a+b$. However, $a \neq b$, so $\text{lcm}(a, b) \geq 2 \cdot \max(a, b) \gt a + b$, which is a contradiction.

For the remaining cases, let $a^k$ be our construction for $n = k$, and let $\sum(a^k)$ be the sum of all elements in $a^k$. We construct $a^k$ recursively for all $k \leq 50$:

- $n = 1$: $a^1 = [1]$.
- $n = 3$: $a^3 = [1, 2, 3]$.
- $n \gt 3$: Construct $a^{n-1}$. Obtain $a^n$ by appending $\sum(a^{n-1})$ to $a^{n-1}$. All elements in $a^n$ must divide $\sum(a^{n-1})$, so they must also divide $\sum(a^n) = 2\cdot \sum(a^{n-1})$.

Since $n \leq 50$ and the sum doubles for all $n \gt 3$, $\sum(a^n) \lt 2^{50} \leq 10^{17}$ as required.

## 2246C - 0mar and Alternating Sums

**Hint 1**

For a subsequence to have an alternating sum of zero, it must contain an even number of elements from every group of equal numbers.


**Hint 2**

The number of ways to pick an even size subsequence is equal to the number of ways to pick an odd size subsequence.


**Hint 2.1**

If the array is of size $n$, there are $2^{n-1}$ ways to pick an odd size subsequence.


**Hint 3**

Try to find a simple formula for the case where there are only positive elements.


**Hint 3.1**

The formula is $2^{n-d}$ where $d$ is the number of distinct elements. This is because you must pick an even size subset from every group of equal numbers, and multiplying all the choices together gives you $2^{n-d}$.


**Hint 4**

Do casework on whether or not you select an odd number of $-1$ elements.


**Solution**
First, let's solve the problem for only positive integers (i.e. $1 \leq a_i \leq 10^9$). For a subsequence to have an alternating sum of zero, it must contain an even number of elements from every group of equal numbers.

**Proof**

The alternating sum of the subsequence $b_1, \ldots, b_m$ is the sum $b_1 - b_2 + b_3 + \ldots + (-1)^{m+1}b_m.$ If $m$ is even, we can pair the terms into the form
 $(b_1-b_2) + (b_3 - b_4) + \ldots + (b_{m-1} - b_{m}).$
Since each of these terms is non-positive, the sum is zero if and only if all the terms are zero, which happens iff the subsequence contains an even number of elements from each group of equal numbers.

If $m$ is odd, we can group the terms as follows:
 $b_1 + (b_3-b_2) + (b_5 - b_4) + \ldots + (b_{m-1} - b_{m-2}).$
Since $b_1 \gt 0$ and all the other terms are non-negative the alternating sum cannot be zero.

Since the number of odd and even length subsequences of a group are equal, the number of subsequences of the array which contain an even number of elements from each group is the product of $2^{(\text{group size} -1)}$ over all numbers, which simplifies to $2^{(n - d)}$, where $d$ is the number of distinct elements in the array.

**Proof that the number of odd and even length subsequences are equal**

Let $S = {1,2,\ldots,n}.$ Our claim is equivalent to the statement that $S$ has $2^{n-1}$ subsets of even size. Let $T$ be a subset of $S$ which does not contain $1$. Then $|T \cup {1}| = |T| + 1,$ so its size has opposite parity. Furthermore this set is unique for $T$. Thus there are exactly $2^{n-1}$ pairs $(T, T \cup {1}),$ and each pair contains exactly one even size subset, so there are $2^{n-1}$ subsets of even size.

Now we consider the full problem, with $a_i$ possibly equal to $-1.$ In this case there exist subsequences with alternating sum zero which do not contain an even number of elements from each group.

Note that the number of subsequences containing an even number of $-1$ elements is $2^{(n - d)}$, since they will cancel each other, hence this reduces to the situation discussed above.

It remains to count the number of subsequences which contain an odd number of $-1$ elements. Let the total number of $-1$ elements in the array be $c$. There are $2^{c-1}$ ways to pick an odd number of them. Given that our subsequence contains an odd number of $-1$ elements, the positive elements of the subsequence must have an alternating sum of $-1.$ This occurs precisely when there exists a pair $(v,v+1)$ such that both $v$ and $v+1$ occur an odd number of times, and the remaining elements all occur an even number of times in the subsequence.

**Proof**

Using the same notation as in the previous proof, we see that $b_1, \ldots, b_m$ must again be even length since otherwise the alternating sum will be positive.

In the case where $b_1, \ldots, b_m$ has even length, we need exactly one of the terms $(b_i - b_{i+1})$ as grouped previously to be equal to $-1.$ This is precisely the characterization given.

For any value $v$ such that both $v$ and $v+1$ occur, we can choose the pair $(v,v+1)$ to be the pair with odd counts. This "flip" does not change the number of choices, since in each group the number of odd and even length subsequences are equal.

Therefore, the answer is $2^{(n - d)}$ if $-1$ isn't present; otherwise it is $2^{(n - d)} \cdot (\ell + 1)$, where $\ell$ is the number of values $v$ such that both $v$ and $v+1$ occur in the array.

## 2246D - diss_quack and Array Game

**Hint 1**

Try to solve the problem with no increments.


**Hint 1.1**

Do casework on whether or not there is an odd element in the array.


**Hint 1.2**

If there is an odd element, the answer is
 $\sum_{i=1}^n (\textsf{popcount}(a_i) + \#\textsf{bits}(a_i) - 1).$
Otherwise you must first remove the minimum LSB from all the elements and then this answer is forced.

This is true because if there is an odd element Bob can always put it in position 2, and force Alice to operate on each element individually.


**Hint 2**

Try fixing the minimum LSB over all $a_i$.


**Solution**

First, consider the situation where all additions have already been done. The total number of moves from this point on is bounded above by $$\sum_{i=1}^n (\textsf{popcount}(a_i) + \# \textsf{bits}(a_i) - 1),$$ since for each set bit Alice can subtract 1, and additionally for every bit Alice can divide by 2 (except when $a_i = 1$).

If there is an odd number in the array, then Bob can achieve this value by swapping an odd number into the 2nd position of the array. In this way, Bob forces each of Alice's moves to operate on a single element, which will either be subtracting 1 from a single element, or dividing a single element by 2.

If there is no odd number in the array, then Alice can divide the entire array by 2 regardless of Bob's decision. Then, we can consider the game in 2 stages:

- Every element is even, and each of Alice's moves divides the entire array by 2.
- Some element is odd, and Bob can move it into the 2nd position for the rest of the game, until only 1 element remains.

Once the game reaches the 2nd stage, the remaining score is given by the above formula.

Since $a_i \leq 10^5$, we can try every possible value of $k$. Note that when $k$ is fixed, Alice will greedily attempt to set each element to some multiple of $2^k$ that minimizes $(popcount + \# bits) - k - 1$. Let $b_i$ be the smallest multiple of $2^k$ that is $\geq a_i$. The maximum value of $(popcount + \# bits) - k - 1$ is $17 + 17 - 1 = 33$, so we can only save $33-1=32$ operations at best. We can check all values $b \in [b_i, b_i + 32]$ that are divisible by $2^k$ to see if we can save more operations than we spend to reach $b$.

For a fixed $k$, the answer will be $k$ plus the sum of the minimum score for all array elements. We can iterate over all $k$, checking each possibility in $O(n \log A)$ time, where $A = \max(a_i)$. The total complexity is $O(n \log^2 A)$.

## 2246E - lce4113 and Security Game

**Hint 1**

You only need to determine one bit of $v$ in order to determine $b.$


**Hint 2**

The case $o = x$ needs to be handled carefully.


**Hint 3**

Try randomization.


**Solution**

Let's show that a deterministic solution does not exist. Suppose $m_0$ and $m_1$ are fixed and declared beforehand, so that the interactor has access to these values before the interaction (as would be the case for a deterministic solution). The interaction may proceed as follows:

- The interactor computes $c = (m_0 \oplus m_1)$.
- The solution sends $x$ to the interactor.
- The interactor responds with $o = x.$
- The solution sends $m_0$ and $m_1$.
- The interactor computes $v_0 = x\,\&\,(\sim c)$ and $v_1 = x\,|\,c.$ By construction, $v_0$ is a submask of $x$, $v_1$ is a supermask of $x$, and $v_0 \oplus v_1 = c = m_0 \oplus m_1.$
- The interactor sends $v_0 \oplus m_0 = v_1 \oplus m_1$ to the solution. In this case, both the triples $(v,\mathrm{ty},b) = (v_0,|,0)$ and $(v,\mathrm{ty},b) = (v_1,\&,1)$ are consistent with the interaction, so there is a choice of $(v,\mathrm{ty},b)$ that will make the solution fail.

We now provide a nondeterministic solution. We will first solve the problem assuming $v$ is nonzero. Query $x = 1$. If the input you receive has a set bit which is not the first bit, you know $\mathrm{ty} = |$. Otherwise, since $v$ is nonzero, it is sufficient to assume $\mathrm{ty} = \&$. In either case you now know some bit of $v$.

If you determined $\mathrm{ty} = \&$, send $m_0 = 1, m_1 = 0.$ The result determines $b$ (assuming $v$ is nonzero), since you know the first bit of $v.$

If you determined $\mathrm{ty} = |$, pick some bit $p$ that you know is $1$ and send $m_0 = 2^p$ and $m_1 = 0$. The result again determines $b$.

It remains to handle the case $v = 0$. Note that in this case the interactor responds to the final query with $m_b,$ which is in the set $\{m_0, m_1\}.$ Is the converse sufficient (i.e., is it enough to check that the interactor returned either $m_0$ or $m_1$)? The answer is yes, unless $m_b \oplus v = m_{1-b}.$ We can design $m_0$ and $m_1$ so that this occurs with negligible probability.

Note that if $v = 0$ then our algorithm determines $\mathrm{ty} = \&$. Additionally, in the algorithm above, the bits in $m_0$ and $m_1$ which are not the first bit are irrelevant, so we can choose them randomly in both $m_0$ and $m_1$. The probability that $m_0 \oplus v = m_1$ is then $2^{-29}$, which is negligible. So we can check before processing this case whether the output given by the interactor matches $m_0$ or $m_1$, and if it does, we assume that $v = 0$ and return the corresponding bit. Otherwise we have $v$ nonzero, so we proceed as described earlier.

## 2246F - Whoname and Unsorted Array

**Hint 1**

Consider the inversion count to check whether or not it is possible.


**Hint 1.1**

It is not possible if $n$ is even and the initial inversion count is odd.


**Hint 2**

Try sorting the elements in the suffix.


**Hint 3**

There is a clever $3$-move operation when you can't add the next element to the suffix.


**Solution**

It is not possible to sort the permutation when $n$ is even and the inversion count is odd, as the operation changes the inversion parity $n-2$ times, which is also even (so the inversion count will remain odd, hence nonzero).

Otherwise, we can show that it is always possible in at most $4n$ moves.

Let $\textsf{op}(i)$ $(1 \leq i \leq n-1)$ be an operation on index $i$. Let $\textsf{find}(v)$ be the index $i$ such that $p_i = v$.

Suppose $1,\ldots, x$ are sorted on the suffix (i.e. $p = [p_1, \ldots, p_{n-x}, 1,2 \ldots,x-1, x]$). We will show how to sort $1,\ldots,x+1$ on the suffix. We consider four cases.

The first case is when $p = [n, 1, 2, \ldots, n-1].$ In this case $n$ must be odd, since $p$ has $n-1$ inversions. We perform the following sequence of operations:

- Perform $\textsf{op}(2)$ $n-2$ times. The permutation becomes $[1, n, 2, \ldots, n-1],$ since $n-2$ is odd.
- Perform $\textsf{op}(1).$ The permutation becomes $[1, 2, ..., n]$ as desired.

The second case is $p = [n-1, n, 1, 2, \ldots, n-2].$ In this case we perform the following operations:

- Perform $\textsf{op}(1)$. The permutation becomes $[n-1, 1, 2, \ldots, n-2, n].$
- Perform $\textsf{op}(n-1)$ $n-2$ times. The permutation once again becomes $[1,2,\ldots,n].$

The third case is when $\textsf{find}(x+1) \neq 1.$ In this case performing the operation on the index $\textsf{find}(x+1)-1$ moves $x+1$ to the end of the permutation while preserving the order of the elements $1,\ldots,x.$

The final case is $\textsf{find}(x+1) = 1.$ Let $p_2 = u$ and $p_3 = v$. We perform the following sequence of operations:

- Perform $\textsf{op}(2).$ The permutation becomes $[u, x+1, \ldots, 1, 2, \ldots, x, v].$
- Perform $\textsf{op}(1)$, transforming the permutation into $[u, \ldots, 1, 2, \ldots, x, v, x+1].$
- Perform $\textsf{op}(n-1),$ making the permutation $[v, u, \ldots, 1, 2, \ldots, x, x+1].$ Note that $1,\ldots,x+1$ are sorted on the suffix as desired.

Since each case requires at most $n$ operations, the total number of operations required to make the permutation non-decreasing is at most $4n.$


**Bonus**

There is a solution that works in $\frac{5n}{3}$ operations.


**Bonus++**

Brute force suggests that it is always possible in at most $n$ moves.
