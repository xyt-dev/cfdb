## 2244A - Iskander and Drawings

**Tutorial**

For a segment of length $l$, the erasing time is $\lceil \frac{l}{2} \rceil$, that is, $\frac{l + 1}{2}$, because its length decreases by $2$ every second, and if the segment length is $1$ or $2$, then the segment is erased in $1$ second. Therefore, the answer — is the erasing time of the longest substring of '#' in $s$.


**Solution**
```cpp
#include <bits/stdc++.h>

using ll = long long;
using namespace std;

void I_love_feblokas();

int32_t main() {
 int32_t tc = 1;
 cin >> tc;
 while (tc-->0) {
 I_love_feblokas();
 }
 return 0;
}

void I_love_feblokas() {
 int32_t ans = 0, cnt = 0;
 int n;
 cin >> n;
 string s;
 cin >> s;
 for (auto &c : s) {
 if (c == '*') {
 cnt = 0;
 } else {
 cnt++;
 }
 ans = max(ans, (cnt + 1) / 2);
 }
 cout << ans << '\n';
 return;
}
```

## 2244B - Nikita and Books
 
**Tutorial**

Books can only be moved to the right, from tower $i$ to tower $i + 1$ (provided that $a_i \gt 1$). Therefore, the total number of books in any prefix consisting of the first $i$ towers can never increase; it can only decrease or remain unchanged.

For the final array to be strictly increasing, the minimum possible number of books in the $i$-th tower is $i$ (since every $a_i \ge 1$ and all values must be distinct integers). Therefore, for every prefix of length $i$, the following condition must hold:
 $\sum_{j=1}^{i} a_j \ge 1 + 2 + \dots + i = \frac{i(i+1)}{2}.$
This condition is both necessary and sufficient. The required arrangement can be obtained by greedily moving all extra books to the right.

 
**Solution**
```cpp
#include <bits/stdc++.h>

using ll = long long;
using namespace std;

void I_love_feblokas();

int32_t main() {
    int32_t tc = 1;
    cin >> tc;
    while (tc-- > 0) {
        I_love_feblokas();
    }
    return 0;
}

void I_love_feblokas() {
    int n;
    cin >> n;
    vector<ll> a(n);
    for (auto &x : a) cin >> x;
    ll cur = 0;
    bool ok = true;
    for (ll i = 0; i < n; ++i) {
        cur += a[i];
        ll need = (i + 1) * (i + 2) / 2;
        if (cur < need) {
            ok = false;
        }
    }
    if (ok) {
        cout << "YES\n";
    } else {
        cout << "NO\n";
    }
}
```

## 2244C - Stepan and Permutation

**Tutorial**

Consider a graph whose vertices are the positions of the array. Connect two positions by an edge if their difference is equal to $x$ or $y$. Then one operation corresponds to swapping along an edge of this graph.

Notice that within each connected component of the graph, the elements can be rearranged arbitrarily. Therefore, the permutation can be sorted if and only if, for every element, its current position and the position where it should end up belong to the same connected component.

It remains to understand what the connected components of this graph look like.

Let $g = \gcd(x, y)$. Any path in the graph consists of steps of length $x$ and $y$. Therefore, when moving along edges, we always change the position index by a multiple of $g$. Hence, we can reach only positions with the same remainder modulo $g$.

Let us show that this condition is sufficient. Since $\gcd(x / g, y / g) = 1$, by Bézout's theorem any multiple of $g$ can be represented as $ax + by$ for some integers $a$ and $b$. In other words, any position with the same remainder modulo $g$ can be reached by a sequence of steps of $\pm x$ and $\pm y$.

It remains only to make sure that such steps can always be performed without leaving the bounds of the array. This is exactly why the condition $x + y \le n$ is given in the statement: it guarantees that within each residue class there is always enough room to replace "out-of-bounds" steps with equivalent ones and move between any two vertices of this class. Thus, each connected component consists exactly of all positions with the same remainder modulo $g$.

Therefore, the permutation can be sorted if and only if for all $i$ we have $p_i \equiv i \pmod g$.


**Solution**
```cpp
#include <bits/stdc++.h>

using ll = long long;
using namespace std;

void I_love_feblokas();

int32_t main() {
 int32_t tc = 1;
 cin >> tc;
 while (tc-- > 0) {
 I_love_feblokas();
 }
 return 0;
}

void I_love_feblokas() {
 int n, x, y;
 cin >> n >> x >> y;
 vector<int> p(n);
 for (auto &val : p) cin >> val;

 int g = gcd(x, y);
 bool ok = true;

 for (int i = 0; i < n; ++i) {
 if ((p[i] % g) != ((i + 1) % g)) {
 ok = false;
 break;
 }
 }

 if (ok) {
 cout << "YES\n";
 } else {
 cout << "NO\n";
 }
}
```

## 2244D - Yaroslav and Productivity
 
**Tutorial**

Sort the posts in increasing order: $b_1 \lt b_2 \lt \dots \lt b_m$. Add $b_0 = 0$. Consider the segments $(b_{k-1}, b_k]$ for $k = 1, \dots, m$ and the last segment $(b_m, n]$.

For the segment $(b_{k-1}, b_k]$, the sign of all elements is determined by the parity of the number of selected posts from the set $\{b_k, b_{k+1}, \dots, b_m\}$. Denote this parity by $y_k \in \{0,1\}$. For the last segment, $y_{m+1} = 0$.

Since the posts can be chosen arbitrarily, $y_1, \dots, y_m$ can be anything. Therefore, for each $k = 1, \dots, m$, we can independently take the sum of the elements on the segment $(b_{k-1}, b_k]$ with either a $+$ or a $-$ sign depending on $y_k$. It is optimal to take the absolute value of this sum. The sign of the last segment cannot be changed. Then the answer is:
 $\sum_{k=1}^{m} \left| \sum_{i=b_{k-1}+1}^{b_k} a_i \right| + \sum_{i=b_m+1}^{n} a_i.$

 
**Solution**
```cpp
#include <bits/stdc++.h>

using ll = long long;
using namespace std;

void I_love_feblokas();

int32_t main() {
    int32_t tc = 1;
    cin >> tc;
    while (tc-->0) {
        I_love_feblokas();
    }
    return 0;
}

void I_love_feblokas() {
    int n, m;
    ll ans = 0;
    cin >> n >> m;
    vector<ll> a(n), b(m);
    for (auto &x : a) cin >> x;
    for (auto &x : b) cin >> x;
    b.push_back(0);
    sort(b.begin(), b.end());
    vector<ll> pref(n + 1);
    for (ll i = 0; i < n; ++i) {
        pref[i + 1] = pref[i] + a[i];
    }
    for (ll i = 1; i < b.size(); ++i) {
        ans += abs(pref[b[i]] - pref[b[i - 1]]);
    }
    ans += pref[n] - pref[b.back()];
    cout << ans << '\n';
    return;
}
```

## 2244E - Masha and the Garland

**Tutorial**

For each of the two beautiful strings, consider the positions where it differs from the original string. Split them into maximal contiguous blocks.

Notice that if we completely invert one of the internal blocks, it disappears and merges the two neighboring blocks into one. Thus, the number of blocks decreases by $2$. If we invert an edge block, the number of blocks decreases only by $1$, so it is not profitable to do that while there are internal blocks.

Therefore, the optimal strategy is to sequentially invert every second block, starting from the second one. After each operation, the number of blocks decreases by $2$, so if initially there were $cnt$ blocks, the minimum number of operations is $\lfloor\frac{cnt}{2}\rfloor$.

It remains to learn how to quickly find the number of blocks for each query. For this, it is enough to precompute an array marking the beginning of each block and its prefix sums. After computing the minimum required number of operations, compare it with $k$.


**Solution**
```cpp
#include <bits/stdc++.h>

using namespace std;

void solve() {
 int n, q;
 cin >> n >> q;
 string s;
 cin >> s;
 vector<int> pref(n, 0);
 for (int i = 0; i < n &mdash; 1; ++i) {
 pref[i + 1] = pref[i] + (s[i] == s[i + 1] ? 1 : 0);
 }
 for (int i = 0; i < q; ++i) {
 int l, r, k;
 cin >> l >> r >> k;
 if (l == r) {
 cout << "YES\n";
 continue;
 }
 int c = pref[r &mdash; 1] &mdash; pref[l &mdash; 1];
 int needed = (c + 1) / 2;
 if (needed <= k) cout << "YES\n";
 else cout << "NO\n";
 }
}

int main() {
 int t;
 cin >> t;
 while (t--) solve();
 return 0;
}
```

## 2244F - Anya Loves Trees!
 
**Tutorial**

In every subtree, the leaves must form a contiguous segment of numbers — otherwise, they cannot appear consecutively in the global increasing sequence. Therefore, we will check this property bottom-up. For each vertex, store the minimum, maximum, and number of leaves in its subtree, as well as whether the vertex satisfies the conditions.

For an internal vertex, look at its children in the given order. Count the number of gaps between neighboring children in the cycle (that is, including the last and the first): call it a gap if the minimum of the next child is not equal to the maximum of the previous one $+1$. If all children satisfy the conditions and there is at most one gap, then a cyclic shift can place the children in the correct order — so the vertex is also good. Otherwise, it is not. If the root satisfies the conditions, then it is possible to sort the values in the leaves; otherwise, it is not.

 
**Solution**
```cpp
#include <bits/stdc++.h>

using ll = long long;
using namespace std;

vector<vector<int>> g;
vector<int> leaf;
bool ok;

void I_love_feblokas();
pair<int, int> dfs(int u, int p);

int32_t main() {
    int32_t tc = 1;
    cin >> tc;
    while (tc-- > 0) {
        I_love_feblokas();
    }
    return 0;
}

pair<int, int> dfs(int u, int p) {
    if (!ok) return {0, 0};
    if (leaf[u] != 0) {
        for (int v : g[u]) {
            if (v != p) {
                ok = false;
                return {0, 0};
            }
        }
        return {leaf[u], leaf[u]};
    }
    vector<pair<int, int>> segs;
    for (int v : g[u]) {
        if (v != p) {
            segs.push_back(dfs(v, u));
            if (!ok) return {0, 0};
        }
    }
    if (segs.empty()) {
        ok = false;
        return {0, 0};
    }
    vector<pair<int, int>> sorted_segs = segs;
    sort(sorted_segs.begin(), sorted_segs.end());
    for (size_t i = 0; i < sorted_segs.size() &mdash; 1; ++i) {
        if (sorted_segs[i].second + 1 != sorted_segs[i + 1].first) {
            ok = false;
            return {0, 0};
        }
    }
    int start_pos = -1;
    for (size_t i = 0; i < segs.size(); ++i) {
        if (segs[i] == sorted_segs[0]) {
            start_pos = i;
            break;
        }
    }
    if (start_pos == -1) {
        ok = false;
        return {0, 0};
    }
    for (size_t i = 0; i < segs.size(); ++i) {
        if (segs[(start_pos + i) % segs.size()] != sorted_segs[i]) {
            ok = false;
            return {0, 0};
        }
    }
    return {sorted_segs[0].first, sorted_segs.back().second};
}

void I_love_feblokas() {
    int n;
    cin >> n;
    g.assign(n + 1, vector<int>());
    leaf.assign(n + 1, 0);
    ok = true;
    for (int i = 2; i <= n; ++i) {
        int p;
        cin >> p;
        g[p].push_back(i);
        g[i].push_back(p);
    }
    int k = 0;
    for (int i = 1; i <= n; ++i) {
        cin >> leaf[i];
        k = max(k, leaf[i]);
    }
    if (n == 1) {
        cout << "YES\n";
        return;
    }
    pair<int, int> res = dfs(1, -1);
    if (ok && res.first == 1 && res.second == k) {
        cout << "YES\n";
    } else {
        cout << "NO\n";
    }
}
```

## 2244G - Yura and Deadlines

**Tutorial**

Note that for any chosen sequence of indices, it is enough to check the condition only for adjacent elements: if for every adjacent pair $(i, j)$ the condition $|i-j| \gt max(a_i, a_j)$ holds, then it will also hold for any pair, since the distance between them is the sum of the distances between adjacent elements, and each of those is strictly greater than the corresponding $a$.

Thus, the problem reduces to choosing a subsequence such that for adjacent $i \lt j$ we must have $j - i \gt max(a_i, a_j)$, which is equivalent to the two conditions $i + a_i \lt j$ and $j - a_j \gt i$.

For each index $j$, define $l_j = j + a_j$. Then the previous chosen index $i$ for $j$ must satisfy $i \lt j - a_j$ and $l_i \lt j$.

We use dynamic programming: $dp[j] = a_j + max(dp[i])$ over all $i$ such that $i \lt j - a_j$ and $l_i \lt j$.

Process the indices from left to right. Maintain a data structure (a Fenwick tree or a segment tree for maximum) into which we add $i$ with value $dp[i]$ as soon as the current index becomes greater than $l_i$. Then for the current $j$, a maximum query on the prefix $[1, j - a_j - 1]$ gives the desired $max(dp[i])$.


**Solution**
```cpp
#include <bits/stdc++.h>

using namespace std;
using ll = long long;

struct Fenwick {
 int n;
 vector<ll> t;

 Fenwick(int n) : n(n), t(n + 1, 0ll) {}

 int f(int x) {
 return x & -x;
 }

 void upd(int pos, ll val) {
 for (; pos <= n; pos += f(pos)) t[pos] = max(t[pos], val);
 }

 ll get(int pos) {
 ll ans = 0;
 for (; pos > 0; pos -= f(pos)) ans = max(ans, t[pos]);
 return ans;
 }
};

void I_love_feblokas() {
 int n;
 cin >> n;
 vector<ll> a(n + 1);
 for (int i = 1; i <= n; ++i) {
 cin >> a[i];
 }
 Fenwick t(n);
 vector<vector<pair<int, ll>>> ev(n + 1);
 ll ans = 0;
 for (int i = 1; i <= n; ++i) {
 for (auto& ev : ev[i]) {
 t.upd(ev.first, ev.second);
 }
 int lim = i - a[i] - 1;
 ll mx = 0;
 if (lim > 0) {
 mx = t.get(min(n, lim));
 }
 ll dp_i = a[i] + mx;
 ans = max(ans, dp_i);
 ll act = i + a[i] + 1;
 if (act <= n) {
 ev[act].push_back({i, dp_i});
 }
 }
 cout << ans << "\n";
}

int main() {
 int t;
 cin >> t ;
 while (t--) {
 I_love_feblokas();
 }
 return 0;
}
```
