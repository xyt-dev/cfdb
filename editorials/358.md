## 358A - Dima and Continuous Line
Author — [Berezin](<https://codeforces.com/profile/Berezin>)

If our line has self-intersections, that some pair of semi-circles exists, which intersect each other.
Let points *x*<sub>1</sub> < *x*<sub>2</sub> are connected with a semi-circle and points *x*<sub>3</sub> < *x*<sub>4</sub> are connected with another semi-circle. Then this semis-circles intersect if one of the conditions is true:

1). *x*<sub>1</sub> < *x*<sub>3</sub> < *x*<sub>2</sub> < *x*<sub>4</sub>
2). *x*<sub>3</sub> < *x*<sub>1</sub> < *x*<sub>4</sub> < *x*<sub>2</sub>

Let’s iterate trough all pairs of semi-circles, and check if the semi-circles intersect each other. So, the solution will have complexity *O*(*N*<sup>2</sup>) what satisfied the constrains.
