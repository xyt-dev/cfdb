## 631E - Product Sum

![](eimages/631_18.png)

The operation, which has been described in the statement, is cyclic shift of some subarray. Let's try to solve this problem separately for left cyclic shift and for right cyclic shift. Let's define

![](eimages/631_19.png)

 as answer before(or without) cyclic shift, Δ*ans* = *ans* - *ans*' — difference between answer after cyclic shift and before. This difference can be found by next formulas:

For left cyclic shift:

Δ~*l*, *r*~ = (*a*~*l*~·*r* + *a*~*l* + 1~·*l* + ... + *a*~*r*~·(*r* - 1)) - (*a*~*l*~·*l* + *a*~*l* + 1~·(*l* + 1) + ... + *a*~*r*~·*r*) = *a*~*l*~·(*r* - *l*) - (*a*~*l* + 1~ + *a*~*l* + 2~ + ... + *a*~*r*~)

For right cyclic shift:

Δ'~*l*, *r*~ = (*a*~*l*~·(*l* + 1) + *a*~*l* + 1~·(*l* + 2) + ... + *a*~*r*~·*l*) + (*a*~*l*~·*l* + *a*~*l* + 1~·(*l* + 1) + ... + *a*~*r*~·*r*) = (*a*~*l*~ + *a*~*l* + 1~ + ... + *a*~*r* - 1~) + *a*~*r*~·(*l* - *r*)
