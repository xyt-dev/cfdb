It is meant that set of all string is splits to equivalence classes. Let's find lexicographic minimal strings what is equivalent to first and to second given string. And then check if its are equals.

It is remain find the lexicographic minimal strings what is equivalent to given. For instance we can do it such a way:

```cpp
String smallest(String s) {
 if (s.length() % 2 == 1) return s;
 String s1 = smallest(s.substring(0, s.length()/2));
 String s2 = smallest(s.substring(s.length()/2), s.length());
 if (s1 < s2) return s1 + s2;
 else return s2 + s1;
}
```
