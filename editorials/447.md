## 446B - DZY Loves Modification
If *p* = 0, apperently the best choice is choosing the row or column which can give greatest pleasure value each time.

Ignore *p* first,then we can get a greatest number *ans*. Then if we choose rows for *i* times, choose columns for *k* - *i* times, *ans* should subtract (*k* - *i*) × *i* × *p*.

So we could enumerate i form 0 to k and calculate *ans*<sub>*i*</sub> - (*k* - *i*) * *i* * *p* each time, max {*ans*<sub>*i*</sub> - (*k* - *i*) * *i* * *p*} is the maximum possible pleasure value DZY could get.

Let *a*<sub>*i*</sub> be the maximum pleasure value we can get after choosing *i* rows and *b*<sub>*i*</sub> be the maximum pleasure value we can get after choosing *i* columns. Then *ans*<sub>*i*</sub> = *a*<sub>*i*</sub> + *b*<sub>*k* - *i*</sub>. We can use two priority queues to calculate *a*<sub>*i*</sub> and *b*<sub>*i*</sub> quickly.
