# B. QR code

**time limit per test:** 2 seconds

**memory limit per test:** 256 megabytes

**input:** stdin

**output:** stdout



![](images/290B_1.gif)



#### Input

The input contains two integers *a*~1~, *a*~2~ (0 ≤ *a*~*i*~ ≤ 32), separated by a single space.

#### Output

Output a single integer.

#### Examples

#### Input
```
1 1
```

#### Output
```
0
```

#### Input
```
3 7
```

#### Output
```
0
```

#### Input
```
13 10
```

#### Output
```
1
```
