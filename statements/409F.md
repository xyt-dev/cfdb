# F. 000001

**time limit per test:** 1 second

**memory limit per test:** 256 megabytes

**input:** stdin

**output:** stdout

#### Input

The input contains a single integer *a* (1 ≤ *a* ≤ 64).

#### Output

Output a single integer.

#### Examples

#### Input
```
2
```

#### Output
```
1
```

#### Input
```
4
```

#### Output
```
2
```

#### Input
```
27
```

#### Output
```
5
```

#### Input
```
42
```

#### Output
```
6
```
