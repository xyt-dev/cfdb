# B. Mike's Sequence

**time limit per test:** 1 second

**memory limit per test:** 256 megabytes

**input:** standard input

**output:** standard output

You won't find this sequence on OEIS.

#### Input

One integer $r$ ($-45 \le r \le 2999$).

#### Output

One integer.

#### Example

#### Input
```
2999
```

#### Output
```
3000
```
