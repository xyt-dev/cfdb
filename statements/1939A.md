This is an interactive problem.
You are given n points Ai = (xi , yi ) on the plane. It is known that all xi are distinct and all yi are distinct.
Your task is to draw polygonal lines connecting these n points.
A polygonal line is defined by a permutation p1 , p2 , . . . , pn of numbers from 1 to n. The polygonal line
consists of n − 1 segments, the first segment connects points Ap1 and Ap2 , the second segment connects
points Ap2 and Ap3 , . . ., the last segment connects points Apn−1 and Apn . Note that segments may intersect.
The sharpness of a polygonal line is defined as the number of indices 2 ≤ i ≤ n − 1 such that the angle
∠Api−1 Api Api+1 is acute, i.e., strictly less than 90◦ .
You need to solve four tasks:

   1. Find any polygonal line that has the maximum possible sharpness.

   2. Given an integer c. Find any polygonal line whose sharpness is ≤ c.

   3. Given an integer c.
      Answer q queries, each specified by a single integer ki (c ≤ ki ≤ n − c). In the i-th query, you need
      to construct a polygonal line that has sharpness exactly ki .

   4. Given an integer c.

Interaction Protocol
The first line contains two integers task, group (1 ≤ task ≤ 4, 0 ≤ group ≤ 21) — the number of the task
to be solved in this test and the test group number.
The second line contains a single integer n (3 ≤ n ≤ 80 000) — the number of points on the plane.
Each of the next n lines contains two integers xi , yi (|xi |, |yi | ≤ 109 ) — the coordinates of the points. It
is guaranteed that all xi are distinct and all yi are distinct.
If task = 1, then the input ends here and you should output any permutation with the maximum possible
sharpness. The interaction ends here.
If task 6= 1, then the next line contains a single integer c (2 ≤ c ≤ n2 ).
If task = 2, then the input ends here and you should output any permutation with sharpness ≤ c. The
interaction ends here.

The next line contains a single integer q (1 ≤ q ≤ 50) — the number of queries.
Then q times, in each line, a query ki (c ≤ ki ≤ n − c) appears. As a response, you should output a
permutation on a separate line. The sharpness of this permutation should be exactly ki . If task = 4, the
hash of this permutation should match the previously provided hash.
Since this is an interactive problem, after outputting each line, do not forget to output a
newline character and flush the output buffer.

Scoring
The tests for this problem consist of twenty-one groups. Points for each group are given only if all tests
of the group and all tests of the required groups are passed.
