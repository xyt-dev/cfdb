# F. Math

**time limit per test:** 1 second

**memory limit per test:** 256 megabytes

**input:** standard input

**output:** standard output

#### Input

The input contains a single integer $a$ ($-100 \le a \le 100$).

#### Output

Output the result – an integer number.

#### Example

#### Input
```
1
```

#### Output
