# C. Without Text

**time limit per test:** 2 seconds

**memory limit per test:** 64 megabytes

**input:** standard input

**output:** standard output



![](images/656C_1.png)


You can preview the image in better quality by the link: [http://assets.codeforces.com/files/656/without-text.png](<https://assets.codeforces.com/files/656/without-text.png>)

#### Input

The only line of the input is a string (between 1 and 50 characters long, inclusive). Each character will be an alphanumeric character or a full stop ".".

#### Output

Output the required answer.

#### Examples

#### Input
```
Codeforces
```

#### Output
```
-87
```

#### Input
```
APRIL.1st
```

#### Output
```
17
```
