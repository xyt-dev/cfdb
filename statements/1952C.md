# C. They Have Fooled

**time limit per test:** 1 second

**memory limit per test:** 256 megabytes

**input:** standard input

**output:** standard output



![](images/1952C_1.png)



#### Input

The first line contains one integer $n$ ($0 \leq n \leq 12$).

#### Output

One integer — the answer.

#### Examples

#### Input
```
0
```

#### Output
```
10
```

#### Input
```
1
```

#### Output
```
10
```

#### Input
```
5
```

#### Output
```
7
```

#### Input
```
9
```

#### Output
```
0
```
