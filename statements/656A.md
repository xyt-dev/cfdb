# A. Da Vinci Powers

**time limit per test:** 2 seconds

**memory limit per test:** 64 megabytes

**input:** standard input

**output:** standard output

#### Input

The input contains a single integer *a* (0 ≤ *a* ≤ 35).

#### Output

Output a single integer.

#### Examples

#### Input
```
3
```

#### Output
```
8
```

#### Input
```
10
```

#### Output
```
1024
```
